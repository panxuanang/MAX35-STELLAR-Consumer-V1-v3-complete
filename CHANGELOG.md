# Changelog

## 1.0.0-consumer-preview

- MAX35 product overlay architecture.
- Three independently replaceable UI pages: Home / Chat / Camera.
- Voice-driven Home -> Chat interaction inspired by the proven STELLAR flow.
- Near-full-screen readable answer surface with delayed one-way long-text scroll.
- Rear-camera homework flow gated by a local touchscreen shutter before native Capture/Explain.
- NVS memo MCP tools with RAM cache to avoid repeated flash reads during UI refresh.
- Weather injection tool; firmware does not invent local weather.
- GitHub Actions build against SpotPear's documented Xiaozhi 3.1.0 / ESP-IDF 5.5 flow.
- Merged BIN packaging plus component images and SHA-256 checksums.
